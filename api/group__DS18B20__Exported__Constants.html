◆ DS18B20_ALARM_SEARCH

#define DS18B20_ALARM_SEARCH   0xEC

DS18B20 Alarm Search ROM command.

Note
Returns only the devices currently in alarm state, i.e. whose last measured temperature is outside the TH/TL thresholds configured with Write Scratchpad (DS18B20_WRITE_SCRATCHPAD).

◆ DS18B20_COPY_SCRATCHPAD

#define DS18B20_COPY_SCRATCHPAD   0x48

DS18B20 Copy Scratchpad command.

Note
Copies the scratchpad (TH/TL/CFG) into the EEPROM (non-volatile). Exposed as a non-blocking transaction (ds18b20_copy_scratchpad()); the resolution state machine does not use it because the config write takes effect immediately.

◆ DS18B20_FAMILY_CODE

#define DS18B20_FAMILY_CODE   0x28

DS18B20 1-Wire family code (LSB of the 64-bit ROM address)

Note
Other 1-Wire devices on the bus use different family codes and are skipped by the device search.

◆ DS18B20_MAX_DEVICES

#define DS18B20_MAX_DEVICES   8

Maximum number of DS18B20 devices tracked by the driver.

Note
Size of the internal device table filled by the device search; the simultaneous-conversion (scan) mode uses it to address every sensor.

◆ DS18B20_READ_POWER_SUPPLY

#define DS18B20_READ_POWER_SUPPLY   0xB4

DS18B20 Read Power Supply command.

Note
