Detailed Description

Library version (semantic versioning).

The single source of the project version: tests/check_version.sh reads these four macros and compares every other declaration site (CMake project(), the PlatformIO manifest, Doxygen, the README FetchContent tag, the CHANGELOG links and the release workflow) against them. A release bump edits this file; nothing else defines the version.
