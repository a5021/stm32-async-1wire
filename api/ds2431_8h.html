Detailed Description

Non-blocking DS2431 1 kbit EEPROM driver for STM32.

This driver implements a strictly non-blocking interface for the DS2431 EEPROM using hardware timers and DMA on STM32 microcontrollers, on top of the public 1-Wire layer primitives (onewire_reset() / onewire_write_slots() / onewire_read_data()). It is a self-contained second driver: it does not touch the DS18B20 driver or the 1-Wire layer internals, and is compiled in the same way ("include-only parts" pulled into one umbrella translation unit).

Key features:

  • Pure bare-metal, register-level programming
  • No interrupts; no software delays or busy-waits in the measurement path
  • Non-blocking state machine architecture (start/poll pairs)
  • Read Memory (0xF0) in passes of up to 8 bytes per bus transaction
  • Full write cycle: Write Scratchpad (0x0F) -> Read Scratchpad (0xAA, TA/ES echo and written-data read-back verified) -> Copy Scratchpad (0x55)
  • Parasite-power support: the strong pull-up is engaged for the t_PROG programming window of Copy Scratchpad (ds2431_set_parasite(1))
  • Optional Match ROM (0x55 + 8-byte ROM) addressing from a bus search; Skip ROM (broadcast) is the default

Device model (DS2431 datasheet): 128 bytes of EEPROM = 4 pages x 32 bytes, written through an 8-byte scratchpad in page-aligned 8-byte blocks. The scratchpad holds the block being written plus the latched target address and the end-offset status byte ES = (address + length - 1) & 0x07. The Read Scratchpad reply ends with an inverted CRC-16 over the command, the target address (TA1/TA2), the E/S byte and the 8 scratchpad data bytes; the driver reads and verifies it (onewire_crc16()) and additionally compares the TA1/TA2/ES echo against what the last Write Scratchpad latched. Because the device computes that CRC over what it actually stored, the read-back data bytes are also compared with the payload that was sent: a byte corrupted on the way to the device during Write Scratchpad passes the CRC and the echo, so only this comparison catches it before Copy Scratchpad commits it.

Usage:

  1. Call ds2431_init() once at startup (instead of ds18b20_init(): the two drivers share the TIM1/DMA/GPIO bus, so only one of them may be used on a bus at a time)
  2. (Optional) Run the non-blocking device search (onewire_search_start() with family code DS2431_FAMILY_CODE) to get a ROM address, then call ds2431_select() so subsequent operations are addressed to that device
  3. Read back memory: ds2431_read_memory() + ds2431_read_memory_poll()
  4. Program a page: ds2431_write_scratchpad() (8-byte block) + poll, then ds2431_read_scratchpad() + poll (verify the TA/ES echo and the written data via ds2431_last_command_ok()), then ds2431_copy_scratchpad() + poll
  5. Partial block writes are read-modify-write at the application level: read the 8-byte block, modify the bytes of interest, write the whole block back
