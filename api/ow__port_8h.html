Detailed Description

Platform port layer for the non-blocking 1-Wire engine.

The 1-Wire layer (onewire.c) and the DS18B20 driver (ds18b20.c) are written against this thin, target-agnostic interface. Each target provides the ow_port_* implementation as a header of static inline functions, so the port layer compiles away to exactly the same register writes as a direct bare-metal implementation: zero call overhead in any build mode, with or without LTO, and no function pointers or runtime dispatch.

Every ow_port_* call schedules exactly one hardware-timed operation on the shared timer/DMA engine and returns immediately; the caller advances by polling ow_port_bus_done(). The CPU is never in the timing-critical path.
