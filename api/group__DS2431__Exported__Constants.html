◆ DS2431_COPY_SCRATCHPAD

#define DS2431_COPY_SCRATCHPAD   0x55

DS2431 Copy Scratchpad command.

Note
Copies the scratchpad into the matching EEPROM block. The EEPROM programming (t_PROG, 10ms max) writes one block in about 11ms; the driver waits DS2431_TPROG_US, engages the strong pull-up for the whole window in parasite mode, then reads the device's completion pattern: 0xAA means the block was programmed, logic 1 means the device refused the copy (PF set, invalid address or copy-protected page) and the driver reports failure.
Takes the same byte value (0x55) as the 1-Wire Match ROM ROM-level command; the two never collide because the ROM-level command phase completes before a device-level command is issued.

◆ DS2431_READ_MEMORY

#define DS2431_READ_MEMORY   0xF0

DS2431 Read Memory command.

Note
Reads memory starting at the address given by the TA1/TA2 argument; the read must stay within EEPROM_SIZE and the driver caps one read pass at DS2431_READ_PASS bytes (the proven Linux driver chunk size).

◆ DS2431_READ_PASS

#define DS2431_READ_PASS   8

Maximum EEPROM bytes read by one Read Memory bus transaction.

Note
1-Wire reads are captured one bit slot per pulse; capping the pass keeps the capture buffer small (kernel-proven 8-byte chunk). Large reads are looped by the application in DS2431_READ_PASS-byte passes.

◆ DS2431_READ_SCRATCHPAD

#define DS2431_READ_SCRATCHPAD   0xAA

DS2431 Read Scratchpad command.

Note
Returns the frame TA1, TA2, ES followed by (E[2:0] - T[2:0] + 1) scratchpad data bytes. On the bus the reply continues with an inverted CRC-16 over the command (0xAA), TA1, TA2, ES and those data bytes; the driver clocks the maximum window (DS2431_SCRATCH_FRAME_CRC) and verifies the CRC with onewire_crc16() over the bytes the device actually transmitted. The TA/ES echo is additionally compared against what the last Write Scratchpad latched, the PF flag (0x20, set when the device received fewer bytes than the scratchpad holds) is rejected, and the read-back data bytes are compared with the payload that was sent, so a write corrupted in flight is not reported as successful.

◆ DS2431_SCRATCH_FRAME

#define DS2431_SCRATCH_FRAME   (DS2431_SCRATCH_SIZE + 3)

Maximum length of the Read Scratchpad reply frame in bytes.

Note
3-byte header (TA1, TA2, ES) + up to 8 scratchpad bytes. The device returns (E[2:0] - T[2:0] + 1) data bytes, so the reply is only DS2431_SCRATCH_FRAME long for a full 8-byte window; ds2431_read_scratchpad() zero-fills the unused tail and the caller reads the real length from the E/S byte.

◆ DS2431_SCRATCH_FRAME_CRC

#define DS2431_SCRATCH_FRAME_CRC   (DS2431_SCRATCH_FRAME + 2)

Maximum wire length of the Read Scratchpad reply in bytes, CRC included.

Note
The (up to 11-byte) frame (DS2431_SCRATCH_FRAME) followed by the two inverted CRC-16 bytes the device transmits (datasheet Read Scratchpad [AAh]). The driver always clocks this many slots - the device drives logic 1 once it has finished transmitting - and verifies the CRC over the (E[2:0] - T[2:0] + 1) bytes that were actually sent; the valid frame is returned to the caller.

◆ DS2431_WRITE_SCRATCHPAD

#define DS2431_WRITE_SCRATCHPAD   0x0F

DS2431 Write Scratchpad command.

Note
Writes up to 8 bytes into the volatile scratchpad and latches the target address with the end-offset status byte ES. Does not touch the EEPROM; it takes effect on Copy Scratchpad (DS2431_COPY_SCRATCHPAD).
