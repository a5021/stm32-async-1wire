Detailed Description

Target-microcontroller facts for the non-blocking 1-Wire engine.

Consolidates the family-specific halves of the former port backends (port/stm32f0/ow_port_f0.h ... port/stm32h5/ow_port_h5.h): which clocks to gate, the PA10 pin-mux tokens, the DMA channel/stream assignment and the request-routing macros, plus the ow_pulse_t width. Everything else, including the merged write+read pass, is the shared TIM1+DMA body in inc/ow_port.h, which includes this file first.

Include order (linear, acyclic): a TU includes onewire.h (or ow_port.h directly), which reaches this file before any engine code, so the family facts are always in scope where the engine uses them.

The CMSIS device header is included per family branch below: on target builds it resolves through the CMSIS device include path, on host-test builds tests/mock/ shadows it with the register mock (keep the mock directory ahead of any real CMSIS directory on the host include path).
