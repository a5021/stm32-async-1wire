◆ ds2413_init()

void ds2413_init ( void )

Initialize the DS2413 driver hardware.

Precondition
Call after MCU reset, after the system clock is configured and before any 1-Wire bus operation.
Note
Calls onewire_init(), which takes exclusive ownership of the shared TIM1/DMA/GPIO resources. The DS18B20 and DS2431 drivers share that bus; all inits may run before any operation, but only one driver may own the timer at a time.
Warning
A second call is a bootstrap operation, not a reinitialization hook.

◆ ds2413_read_pio()

uint8_t ds2413_read_pio ( uint8_t * out)

Read the PIO pin states (non-blocking).

Parameters
[out]outDestination byte; on success it receives the PIOA/PIOB levels in bits 0/1 (DS2413_PIOA, DS2413_PIOB), the same layout ds2413_write_pio() takes
Returns
1 if the read was scheduled, 0 if the request was rejected (NULL destination, an operation in flight, or a device search running)
Note
The result is valid only when ds2413_read_pio_poll() returns 1 and ds2413_last_command_ok() is 1. out must stay valid until then.

◆ ds2413_select()

void ds2413_select ( const uint8_t * rom)

Select the DS2413 to address.

Parameters
[in]romPointer to the 8-byte ROM address (LSB first), or NULL to use Skip ROM (broadcast)
Note
Accepted only while the driver is idle and no search is running. With a non-NULL ROM the driver sends Match ROM before every command. A broadcast read is only meaningful with one DS2413 on the bus.

◆ ds2413_write_pio()

uint8_t ds2413_write_pio ( uint8_t states)

Write the PIO output latches (non-blocking).

Parameters
[in]statesPIOA/PIOB latch levels in bits 0/1 (DS2413_PIOA, DS2413_PIOB); other bits are ignored
Returns
1 if the write was scheduled, 0 if the request was rejected (an operation in flight or a device search running)
Note
Both latches are written together. To change one channel, read the current state first and pass the modified byte; the device has no read-modify-write command. A broadcast write addresses every DS2413 on the bus.
