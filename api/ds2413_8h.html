Detailed Description

Non-blocking DS2413 dual-channel addressable switch driver.

The DS2413 has two open-drain PIO pins (PIOA, PIOB). A write sets both output latches; a read returns the actual pin levels and the latches separately (the pin equals its latch when the pin is not driven externally). The device is parasite powered: the driver primes it with a 1 ms strong pull-up before each operation, then releases the bus for the reset/command/reply sequence. A failed reply is retried up to three times.

The driver follows the same non-blocking start/poll discipline as the DS18B20 and DS2431 drivers and shares the TIM1/DMA/GPIO bus with them: one operation at a time, no concurrent polling of two drivers.

Wire protocol (DS2413 datasheet, also used by the Linux w1_ds2413 driver):

  • PIO Access Read [F5h]: one reply byte; in the low nibble bit 0 is the PIOA pin, bit 1 the PIOA latch, bit 2 the PIOB pin and bit 3 the PIOB latch; bits 4-7 are its complement. 0xFF means the device did not answer; a byte whose low nibble is not the complement of its high nibble is rejected. The driver normalizes both halves to the write layout (bit 0 = PIOA, bit 1 = PIOB): pins in ds2413_last_pio() / the read destination, latches in ds2413_last_latches().
  • PIO Access Write [5Ah]: the master sends the state byte (bits 0/1 are PIOA/PIOB, bits 2-7 must be 1) followed by its complement, then reads one acknowledge byte. 0xAA means the write was accepted.

Addressing: ds2413_select() chooses Match ROM (0x55 + 8-byte ROM) for one device or Skip ROM (0xCC) for a broadcast. Broadcast write is useful to set several switches at once. Broadcast read is allowed but only meaningful with a single DS2413 on the bus: several devices answering at once produce a wired-AND of their replies, which the driver cannot attribute.
