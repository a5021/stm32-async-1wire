void ds2431_copy_scratchpad ( void  )

Copy the scratchpad into the EEPROM (non-blocking)

Note
Programs the EEPROM block selected by the last Write Scratchpad (target address + ES). The driver waits the t_PROG hold-off (11ms), holds the strong pull-up for the whole window in parasite mode, then reads the device's completion pattern and sets the success flag only for 0xAA (logic 1 = the device refused the copy: PF set, invalid address or copy-protected page). Ignored unless a Write Scratchpad completed since the last reset/select.

◆ ds2431_init()

void ds2431_init ( void  )

Initialize DS2431 driver hardware and peripherals.

Precondition
Call exactly once after MCU reset, after the system clock is configured and before any 1-Wire bus operation.
Note
Calls onewire_init(), which takes exclusive ownership of the shared TIM1/DMA/GPIO resources for the lifetime of the driver (until reset). The DS18B20 driver and the DS2431 driver share that bus ownership, so call ds2431_init() INSTEAD of ds18b20_init(); mixing the two drivers on one bus is unsupported.
Warning
A second call is unsupported and does not fully reset the timer, DMA, low-power or DS2431 software state.

◆ ds2431_read_scratchpad()

void ds2431_read_scratchpad ( uint8_t *  buf)

Read the scratchpad frame (non-blocking)

Parameters
[in,out]bufBuffer for TA1, TA2, ES and the scratchpad bytes; written on success. The caller reads the real data length from the E/S byte (buf[2] & 0x07); bytes beyond the reply window are zeroed, so the buffer is always DS2431_SCRATCH_FRAME long.
Note
The device returns (E[2:0] - T[2:0] + 1) data bytes: the driver clocks the maximum reply and verifies the inverted CRC-16 over what was actually transmitted. When a Write Scratchpad completed since the last reset/select, the driver verifies the echoed TA1/TA2/ES against the latched values, rejects a set PF flag (incomplete write) and compares the read-back data with the payload that was sent; it clears the success flag on any mismatch (ds2431_last_command_ok() reports 0). Without a pending write there is nothing to compare against, so the frame is returned with the flag set from presence.

◆ ds2431_select()

void ds2431_select ( const uint8_t *  rom)

Select which DS2431 device to address by its ROM address.

Parameters
[in]romPointer to the 8-byte ROM address (LSB first), or NULL to return to Skip ROM (broadcast) addressing
Note
With a non-NULL address the driver sends Match ROM (0x55) plus the device address before every command, so only that device responds. The address should come from a family-filtered device search (onewire_search_start(sink, max, DS2431_FAMILY_CODE)).
Applies only while the driver is idle. A select() clears the latched write-cycle state (pending TA/ES): address the same device for the whole write_scratchpad -> read_scratchpad -> copy_scratchpad cycle.

void ds2431_set_parasite ( uint8_t  parasite)

Declare the bus as parasite-powered.

Parameters
[in]parasite1 = devices are powered over the data line, 0 = external VDD supply (default)
Note
Drives the DS2431 EEPROM programming hold-off (t_PROG) through the strong pull-up (bus pin switched to push-pull HIGH), then releases the line back to the passive pull-up. Call once after ds2431_init() or between operations; applies to all subsequent Copy Scratchpad runs.

◆ ds2431_write_scratchpad()

uint8_t ds2431_write_scratchpad ( uint16_t  addr,
const uint8_t *  data,
uint8_t  len 
)

Write up to 8 bytes into the scratchpad (non-blocking)

Parameters
[in]addrBlock-aligned target address in EEPROM
[in]dataData to write to the scratchpad
[in]lenBytes to write, 1 .. DS2431_SCRATCH_SIZE; addr + len must not exceed DS2431_EEPROM_SIZE
Returns
1 if the Write Scratchpad was scheduled, 0 if the request was rejected (NULL data, len out of range, addr + len beyond the EEPROM, addr not 8-byte aligned, or an operation is already in flight / a search is running)
Note
The EEPROM is programmed in 8-byte blocks: addr must be 8-byte aligned (a misaligned addr is rejected) and len should be the full block. A shorter len leaves the remaining scratchpad bytes stale, sets the device's PF flag, and Copy Scratchpad then refuses the block; the driver reports that as a failure (ds2431_read_scratchpad() and ds2431_copy_scratchpad() both clear the success flag). The write only fills the volatile scratchpad; run ds2431_read_scratchpad() to verify and ds2431_copy_scratchpad() to program the EEPROM.
